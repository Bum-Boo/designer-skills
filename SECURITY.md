# Security and private inputs

Skills are instructions that may lead an agent to run local tools. Review the requested paths and operations. Keep credentials, client source files and private project records out of issue reports and contributed examples.

The included tools run locally. Installing skill files does not authorize paid generation, account access or publishing. Use the permissions already granted for the actual task.

For a sensitive report, use a private contact route listed on the repository owner's GitHub profile rather than posting secrets in a public issue. For ordinary reproducible bugs, provide a minimal synthetic example, version and observed result.

The optional MCP server runs with your local OS permissions. Its file-tool paths are bounded to an explicit workspace, but Blender may resolve external resources and is not sandboxed. Use trusted scenes. AE scripting is opt-in and grants native project/file privileges; keep the loopback token and script job files private. After an ambiguous native timeout, inspect retained evidence before any retry. See [MCP setup and recovery](docs/mcp.md).
