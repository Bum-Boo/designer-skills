# 원본 분석

## 확보와 판독

레퍼런스 링크를 실제 열거나 접근 가능한 공개 원본을 확인한다. 영상 대신 페이지 캡션만 확보했다면 그 범위를 명시한다. 접근이 필요한 상태면 승인된 브라우저 경로를 사용하고, 확보하지 못한 이미지를 본 것으로 처리하지 않는다.

로컬 영상이 있으면 대표 조작 전·중·후 프레임을 실제 시간으로 추출한다. 모드/패널을 읽는 프레임과 동작 타이밍을 읽는 구간은 목적에 맞게 선택한다. 전체 프레임과 원본 해상도 crop을 함께 보존한다. 영상 자체 편집·제작은 해당 전문 스킬로 넘긴다.

브라우저/플레이어 chrome, 타이틀바, 여백, 비교 영상의 위아래 장면을 객체의 viewport와 구분한다. 패널 크기·좌표는 장면 기준으로 재고 확대율을 기록한다. 예를 들어1280×1620 비교 프레임은1280×720 장면 두 개와 상단 영역일 수 있다. 임의1.5배 축척을 원본 CSS라고 단정하지 않는다.

## 대조표

기존 프로젝트의 요구/검증 문서에 아래 항목을 추가한다. 별도 진행 장부는 만들지 않는다.

| 항목 | 실제 근거 | 예상 조작/결과 | 현재 앱 | 판정/다음 확인 |
|---|---|---|---|---|
| 객체 모양·표면 | 파일/시각/viewport | 실루엣·재질·그림자 | 코드/화면 | 관찰 또는 근사 |
| 도구·변형 | 조작 전중후 구간 | 잡기/놓기/회전 등의 변화 | 구현 상태 | 기능+화면 확인 |
| 패널 | 원본 crop/모드 | 라벨·순서·기본값·선택 상태 | DOM/상태 | 읽힌 항목만 확정 |
| 패널 밖 출력 | 전체 장면 | 통계·배지·접힘/펼침 | 위치/데이터 | 끝까지 접근 확인 |

“있는 기능 다”는 관찰 가능한 컨트롤/행동을 항목별로 확인하라는 뜻으로 처리한다. 읽지 못한 이름·범위·단위를 임의 기능으로 채우지 않는다. 모드별 항목, 눌렀을 때 달라지는 상태, reset/pause와의 관계도 포함한다.

## 모션 대조

동작은 궤적·주기·반응 시간·감쇠·복원으로 나눠 확인한다. 꼬리/몸의 파동, 잡은 위치에 따른 변형, 놓을 때 관성, 먹이/절단 후 상태를 영상의 실제 시간과 대조한다. slow-motion이나 빠른 편집이 있으면 해당 구간을 정상 속도의 물리 기준으로 쓰지 않는다.

원본의 WEBGPU 배지, 그램 출력, 물리 상수는 로컬 앱의 실제 엔진/단위와 구분한다. 관찰한 기본값을 적용하는 것이 승인 범위인지 판단하고, 기존 기능 보정에서 관련 없는 물리 defaults를 조용히 바꾸지 않는다. 단위 환산이나 근사 표시는 사용자가 오해하지 않게 필요한 곳에서 설명한다.

## 보정에서 자주 놓치는 항목

패널을 맞출 때 모드별 옵션, 별도 통계, 펼친 설명의 끝과 낮은 창의 가림을 함께 확인한다. 절단 기능은 횟수뿐 아니라 절단면·새 조각의 독립 조작·색상/메시/물성 옵션 상속을 확인한다. 이런 항목은 해당 원본에 관찰되거나 사용자가 요구했을 때 적용하며 모든 장난감의 필수 기능으로 만들지 않는다.

과거 기록은 당시 근거다. 실제 이미지 판단은 파일을 열어 수행하고, 이전 APPROVE나 캡처 파일 이름을 새 버전의 검사로 대신하지 않는다.
