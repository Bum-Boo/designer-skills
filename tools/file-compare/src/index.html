파일 경로와 크기 비교
상태경로기준 크기받은 크기

비교 범위와 사용법

원본에서 ‘기준 목록 저장’을 누르고, 다른 기기에서 그 JSON을 ‘목록 불러오기’로 열면 원본 폴더 없이도 받은 파일을 비교합니다. HTML과 JSON을 USB나 동기화 폴더로 옮겨 쓰세요.

같은 상대 경로와 파일 내용을 SHA-256으로 비교합니다. 복사·동기화·편집을 끝낸 뒤 폴더를 선택하세요. 숨김 파일도 브라우저가 제공하면 비교에 포함합니다.

빈 폴더, 수정 시각, 접근 권한, 영상·디자인의 완성도, AE·Blender의 연결 자산은 검사하지 않습니다. ZIP은 풀어서 선택하세요. 브라우저는 심볼릭 링크·정션 여부를 구별하지 못하므로 링크 검사에는 기존 delivery_manifest.py를 사용하세요.

이름의 대소문자나 한글 표기 방식(NFC/NFD)이 다르면 별도 파일로 표시합니다. 목록은 최대 32 MiB, 파일은 200,000개까지 지원합니다. 최신 데스크톱 브라우저를 권장합니다.

파일 목록과 결과 JSON에는 파일명·크기·해시가 들어 있습니다. 개인 자료의 목록도 개인 기기에만 보관하세요. 이 페이지는 결과를 따로 저장하거나 업로드하지 않으며, 닫으면 선택한 파일과 결과가 사라집니다.
