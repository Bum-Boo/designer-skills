# Designer Skills

**English** | [한국어](README.ko.md) | [日本語](README.ja.md) | [中文](README.zh-CN.md)

Multimodal production workflows for designers, packaged as installable agent skills.

Turn a reference or brief into work you can keep editing: a Blender scene, an After Effects project, an interactive prototype, or a checked delivery folder. Each skill defines the deliverable, the editable controls and how to inspect the actual result.

**Preview · 0.2.0-alpha.1** — four focused skills. Bundled tools and instructions have different validation scopes; see [validation](docs/validation.md).

![Product scene generated by the included Blender template](docs/images/blender-product.png)

## Pick a workflow

| Skill | Ask for | What it adds | Requirements |
|---|---|---|---|
| [blender-production](skills/blender-production/SKILL.md) | A product render and editable `.blend` | Configurable device starter, scene builder, fresh-process inspector | Blender; CPU or supported GPU |
| [after-effects-production](skills/after-effects-production/SKILL.md) | Motion graphics you can continue editing | Native layers, practical comp structure, preview and editing guide | After Effects + your scripting/bridge route |
| [reference-to-web-toy](skills/reference-to-web-toy/SKILL.md) | A reference turned into a working interaction | Motion/control inventory, browser comparison, artifact verifier | Browser automation; Python for verifier |
| [asset-delivery](skills/asset-delivery/SKILL.md) | A delivery folder or ZIP checked for omissions | File counts, SHA-256, archive checks and baseline comparison | Python 3.12+ |

The four skills are independently installable. Applications and accounts are separate requirements. The repository also supplies a local MCP server and optional AE CEP companion; install and register them separately from skills.

Four [production helpers](docs/tools.md) ship inside the skill folders. [Designer Tools MCP](docs/mcp.md) exposes file checks, Blender generation/inspection and an optional AE connection.

## Install

With Node.js 22.20 or later, use the [Skills CLI](https://github.com/vercel-labs/skills). Run from your working project:

```bash
npx skills@latest add Bum-Boo/designer-skills
```

Choose skills and agents interactively. To install one explicitly:

```bash
npx skills@latest add Bum-Boo/designer-skills --skill blender-production -a codex
```

Replace `codex` with `claude-code`, `hermes-agent` or another supported agent. Add `-g` for a user-wide installation. Review existing skills with the same names before replacing them. This installs skill files; it does not install Blender, Adobe apps or MCP servers.

For an offline/manual setup, clone or download the repository and copy each selected **whole skill directory**, including its `LICENSE`, into the skill directory supported by your agent. Keep bundled scripts and references together. See [installation details](docs/installation.md).

## Optional MCP server

Install the server from this same repository, then register its command and working-project path in your agent. Node.js 22.20+ is required; Python and Blender are needed only for their tools. AE requires the separate included CEP panel setup. [Installation, configuration examples and limitations](docs/mcp.md).

```bash
git clone https://github.com/Bum-Boo/designer-skills.git
cd designer-skills
npm ci --ignore-scripts
```

## Try it

Use the installed skill's name in your request. Explicit slash or dollar syntax varies by agent; plain language also works when the agent discovers skills automatically.

```text
Use blender-production to create an editable product scene from the included
example. Render a test image, reopen the saved scene and show what I can edit.

Use after-effects-production to make this title sequence as an editable AEP.
Keep the copy and timing accessible and include a preview and editing guide.

Use reference-to-web-toy to recreate the visible controls and interaction in
this reference. Compare real browser behavior with what is actually visible.

Use asset-delivery to compare this handoff ZIP with the approved folder.
Show missing, added or changed files without modifying either source.
```

## What belongs here

Production workflows developed around editable artifacts, visual observation and verifiable handoff. The collection covers 3D, motion, interaction and delivery; it can grow into image/video generation and other designer tools after their dependencies and real outputs are checked.

Unmodified vendor skills and general coding collections stay upstream. This repository is not a bundle of all installed skills. See [scope and next candidates](docs/scope.md) and [provenance](docs/provenance.md).

## Check the package

```bash
python scripts/validate.py
python skills/asset-delivery/scripts/test_delivery_manifest.py
python skills/reference-to-web-toy/scripts/test_verify_static_artifact.py
```

Blender checks require Blender; follow the commands in its skill. File checks and tests do not prove visual quality or automatic skill selection. See [validation](docs/validation.md) for observed checks and remaining limits.
